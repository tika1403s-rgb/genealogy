## What this document is

The single-page reference for *what counts as good output* — source quality bar, citation format expectations, dispute documentation expectations, accessibility expectations.

## Current authoritative content

Quality is currently defined across four documents. This file aggregates the pointers:

- **Data quality** — `core/ontology_definition.md`
  - Required fields on every node and edge
  - Confidence score rubric (A/B/C/D/X) — what evidence justifies each
  - Evidence type rubric (E1–E6) — what each type covers
  - Date precision conventions
  - ID conventions
- **Process quality** — `core/audit_framework.md`
  - Gate enforcement (three gates, three tiers)
  - Quantitative metrics with target/critical/fail thresholds
  - Sign-off requirements before delivery
- **Behavioral quality** — `evolving_rules/`
  - `always_do_this.md` — positive rules every chat must follow
  - `never_do_this.md` — forbidden patterns
  - `common_mistakes.md` — mistakes observed and the rules that prevent recurrence
  - `best_practices.md` — discovered improvements
- **Source quality** — `chat_specific/source_librarian_instructions.md`
  - The anti-fabrication discipline
  - Target distribution of evidence types per era
  - Geographic diversity requirements

## When this file will be expanded

When the four sources above start to disagree or when an operational question (e.g., "what's the minimum citation format for a journal source?") cannot be answered by any of them, the Curator promotes the resolution into this file.

Like `workflow_procedures.md`, this is a placeholder for content that will grow into a standalone reference. At v1.0 it is a pointer.
