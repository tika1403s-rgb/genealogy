## Usage for Knowledge Graph Construction

### Suggested Graph Structure

**Node Types**:
- Field nodes (traditions/schools)
- Pioneer nodes (individual practitioners)
- Breakthrough nodes (concepts/technologies)
- Work nodes (texts)
- Location nodes (Alexandria, Taxila, etc.)

**Edge Types**:
- "Contributed to" (Pioneer → Field)
- "Achieved" (Pioneer → Breakthrough)
- "Authored" (Pioneer → Work)
- "Built upon" (Pioneer → Pioneer)
- "Transmitted" (Field → Field, with temporal/geographic metadata)
- "Studied at" (Pioneer → Location)

**Metadata Fields**:
- Date ranges (century-level granularity)
- Geographic region
- Source citations
- Confidence level (for disputed claims)

### Temporal Modeling
Use century-level buckets (700-600 BCE, 600-500 BCE, etc.) with fuzzy boundaries for pioneers with uncertain dates. Flag "flourished" dates vs. precise birth/death where known.
